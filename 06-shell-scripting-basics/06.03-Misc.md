# <span style="color: #aa2070;"> **1. Input / Output Redirection (`>`, `>>`, `<`)**

Redirection controls **where input comes from** and **where output goes**.

### Operators

| Operator | Purpose                     |
| -------- | --------------------------- |
| `>`      | Redirect output (overwrite) |
| `>>`     | Redirect output (append)    |
| `<`      | Redirect input              |

### Examples

```bash
echo "Hello" > file.txt
echo "World" >> file.txt
```

```bash
wc -l < file.txt
```

---

# <span style="color: #aa2070;"> **2. Pipes (`|`)**

Pipes send the **output of one command** as **input to another command**.

### Syntax

```bash
command1 | command2
```

### Example

```bash
ps aux | grep nginx
```

Common in **log processing and monitoring**.

---
# <span style="color: #aa2070;"> **3. Here Documents (EOF)**

Used to provide **multi-line input** to a command or script.

### Syntax

```bash
command << EOF
text
EOF
```

### Example

```bash
cat << EOF
This is line one
This is line two
EOF
```

Commonly used for **config generation** and **automation scripts**.

---


# <span style="color: #aa2070;"> **4. File Test Operators (`-f`, `-d`, `-r`, `-w`, `-x`)**

Used to check **file properties** in conditions.

| Operator | Meaning            |
| -------- | ------------------ |
| `-f`     | Regular file       |
| `-d`     | Directory          |
| `-r`     | Read permission    |
| `-w`     | Write permission   |
| `-x`     | Execute permission |

### Example

```bash
if [ -f file.txt ]; then
  echo "File exists"
fi
```

# <span style="color: #aa2070;"> **5. Debugging Scripts (`set -x`, `set -e`)**

Used to **debug and control script execution**.

### `set -x` (Debug Mode)

```bash
set -x
echo "Debugging enabled"
```

Prints each command before execution.

### `set -e` (Exit on Error)

```bash
set -e
false
echo "This will not run"
```

Stops script on first failure.

# <span style="color: #aa2070;"> **6. Error Handling Patterns** 

### Check Exit Status (`$?`)

```bash
command
if [ $? -ne 0 ]; then
  echo "Command failed"
fi
```

### Using `||`

```bash
mkdir data || echo "Directory creation failed"
```

### Using `trap`

```bash
trap "echo Error occurred" ERR
```

Essential for **production-grade scripts**.

# <span style="color: #aa2070;"> **7. Sourcing Files (`source`, `.`)** 

Used to **load variables and functions** from another file into the current shell.

### Syntax

```bash
source config.sh
```

or

```bash
. config.sh
```

### Example

```bash
# config.sh
APP_NAME="MyApp"
```

```bash
source config.sh
echo $APP_NAME
```

Common in **CI/CD pipelines**.

---

# <span style="color: #aa2070;"> **7. Associative Arrays** 

Store **key-value pairs** (Bash 4+).

### Syntax

```bash
declare -A user
user[name]="John"
user[role]="Admin"
```

### Access

```bash
echo "${user[name]}"
```

Useful for **structured data** in scripts.

# <span style="color: #aa2070;"> **8. Cron Jobs / Scheduling** 

Cron is used to **schedule scripts**.

### Crontab Syntax

```bash
* * * * * command
```

| Field   | Meaning |
| ------- | ------- |
| Minute  | 0–59    |
| Hour    | 0–23    |
| Day     | 1–31    |
| Month   | 1–12    |
| Weekday | 0–6     |

### Example

```bash
0 2 * * * /backup.sh
```

Runs daily at 2 AM.

# <span style="color: #aa2070;"> **9. Case Sensitivity & Locale** 

### Case Sensitivity

```bash
var=10
VAR=20
```

Both are different variables.

### Locale

Locale affects **sorting, date, and language behavior**.

```bash
echo $LANG
```

Set locale if scripts behave inconsistently.
